# ASP.NET Core 9 MVC Project

This project contains both Admin and Website areas in a single ASP.NET Core 9 MVC application. Each area has its own controllers and views, with shared authentication and resources.

## Structure
- **Areas/Admin**: Admin controllers and views
- **Areas/Website**: Website controllers and views

## Getting Started
1. Install .NET 9 SDK
2. Run `dotnet build` to build the project
3. Run `dotnet run` to start the application

## Customization
- Add controllers and views to each area as needed
- Configure authentication in `Startup.cs` or `Program.cs`
